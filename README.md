## ✨ Uygulamanın Özellikleri

✅ **📋 Günlük Plan Yönetimi**
- Günün herhangi bir saatinde plan ekle
- Her plan için bildirim saati belirle
- Planları tamamlandı olarak işaretle veya sil

✅ **💪 Motivasyon Bildirimleri**
- Gün boyu 5 farklı saatte motivasyon sözleri
- 35+ özel olarak yazılmış motivasyon sözü
- Saate göre kategorize edilmiş sözler

✅ **🔔 Bildirim Sistemi**
- Otomatik bildirim zamanlaması
- Ses ve titreşim desteği
- Arka planda çalışan bildirim servisi

✅ **💾 Yerel Veri Depolama**
- AsyncStorage ile güvenli depolama
- İnternet bağlantısı gerekmez
- Tüm veriler cihazda kalır

## 📞 Hızlı Referans

### Dosyaları Çıkart
```bash

cd plan-ve-motivasyon-app
```

### Git Komutları
```bash
# GitHub'a bağla
git remote add origin https://github.com/KULLANICI_ADIN/plan-ve-motivasyon-app.git

# GitHub'a yükle
git push -u origin main

# Güncellemeleri yükle
git push
```
